# Translations

Spanish translation by Coralys.

Spanish is included in The Armory. Select Spanish in Hytale's language settings.
No separate translation pack is needed.

Language files live in `src/main/resources/Server/Languages`. Each language contains
`server.lang` for item names, descriptions and bench screens, and `client.lang` for
the custom tooltip stat labels. Spanish uses `es-ES`, including the regional Spanish
languages that Hytale maps to it.

When updating a translation, keep every key and named parameter from the English
files. Translate the values, including the words inside plural expressions. Keep
formatting tags, color codes and item identifiers intact. Save the files as UTF-8.
